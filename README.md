## 🚀 About the Project

**Elevate** is a modern, full-stack web application that leverages artificial intelligence to generate, administer, and evaluate technical assessments in real-time. The platform supports multiple programming languages and domains, offering both MCQ-based and code-based assessments with intelligent AI evaluation and detailed performance analytics.

This project was developed as a **Final Year Project (FYP)** at the university level to demonstrate expertise in full-stack development, AI integration, and modern UI/UX design principles.

---

## ✨ Features

| Feature                           | Description                                                                                                                      |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 🤖 **AI-Generated Assessments**   | Questions are dynamically generated by AI (via OpenRouter) based on the selected skill and test format — no two tests are alike. |
| 💻 **Live Code Editor**           | Integrated Monaco Editor (VS Code engine) for real-time code writing during assessments.                                         |
| 📊 **AI-Powered Evaluation**      | Submissions are evaluated by AI with detailed scoring, feedback, and explanations for each answer.                               |
| 🏅 **Badge & Achievement System** | Gold, Silver, and Bronze badges are awarded based on performance thresholds.                                                     |
| ⏱️ **Timed Assessments**          | Built-in countdown timer with automatic submission when time expires.                                                            |
| 🛡️ **Anti-Cheat Protection**      | Tab switching and window switching are detected — any violation immediately ends the test.                                       |
| 🔙 **Back-Button Protection**     | Navigating back during a test triggers automatic submission with zero score.                                                     |
| 🤝 **AI Chat Assistant**          | In-test AI assistant for hints and guidance (without giving away answers).                                                       |
| 📱 **QR Code Login**              | Modern QR-based authentication flow with demo mode for quick access.                                                             |
| 📈 **Performance Dashboard**      | Visual trajectory charts, score history, and badge collection overview.                                                          |
| 🎨 **Premium UI/UX**              | Glassmorphism, micro-animations, magnetic buttons, sparkle effects, and a sleek gray gradient design system.                     |

| **UI Components**    | Radix UI + shadcn/ui (New York theme)                              |

## ⚡ Getting Started

### Prerequisites

- **Node.js** >= 22.12.0
- **npm** >= 10

### Installation

```bash
# Clone the repository
git clone https://github.com/stack-crafter/Elevate-SaaS.git
cd Elevate-SaaS

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Edit .env and add your OpenRouter API key
```

### Configuration

Edit the `.env` file with your credentials:

```env
VITE_OPENROUTER_API_KEY="sk-or-v1-your-api-key-here"
VITE_OPENROUTER_MODEL="openai/gpt-4o-mini"
```

> 💡 Get your API key at [https://openrouter.ai/keys](https://openrouter.ai/keys)
>
> Browse available models at [https://openrouter.ai/models](https://openrouter.ai/models)

### Run Locally

```bash
npm run dev
```

The app will be available at `http://localhost:5173/`

### Build for Production

```bash
npm run build
npm run preview
```

## 🎮 How It Works

1. **Login** — Scan the QR code or use the demo mode for quick access.
2. **Select** — Choose your skill (React, Python, Java, AI, etc.) and test format (MCQ or Pure Code).
3. **Test** — AI generates unique questions. Answer within the time limit using the built-in code editor.
4. **Results** — AI evaluates your answers and provides detailed scoring with explanations.
5. **Badge** — Earn Gold (85+), Silver (70+), or Bronze (50+) badges based on your score.
6. **Dashboard** — Track your progress over time with visual charts and badge collection.

## 🔒 Security

- API keys are stored in `.env` (git-ignored) and accessed via `import.meta.env`
- No secrets are committed to the repository
- Anti-cheat system prevents tab/window switching during assessments
- Back-button navigation is blocked during active tests
